# Merge notes

This folder is the combination of two copies of MedOS. Neither source folder was changed.

| Source | Folder |
|---|---|
| **A** (the copy worked on in this session) | `medos-testing-medos-update-2/medos-testing-medos-update-2026-11-06` |
| **B** (the other copy) | `medos-testing-medos_chakravardhan/medos-testing-medos_chakravardhan` |

Both started from the same code (the files neither side changed are identical, and `pnpm-lock.yaml` is the same). Each side then added its own work, so the merge keeps every change from both; nothing was removed.

## From A (kept)

- **New bill** is added to today's OPD visit (`apps/web/src/lib/visit-for-bill.ts` and its test, `billing/page.tsx`), so the booking and earnings reports and the doctor's share count it.
- **Use advance** button refreshes its balance and uses a fresh idempotency key (`advance-extras.tsx`).
- **Cashier can open the Appointments list** (read only) to take the booking fee: `APPOINTMENT_READ` for CASHIER in `packages/shared/src/permissions.ts`, migration `20261107100000_cashier_reads_appointments`, test in `appointments.spec.ts`.
- **Advance section on the printed invoice** (HTML and PDF): `print.service.ts` and `print.spec.ts`.
- Bengali and Hindi text for the new bill notice; documentation (`advance-payments.md`, `booking-fee.md`, `earnings-and-reports.md`).

## From B (kept)

- **Live notifications pushed the moment they commit** (`notifications.service.ts`, `common/after-commit.ts` and its test, `prisma.service.ts`, the web proxy and `notifications.tsx`).
- **Telemedicine stages 2 and 3**: service, domain, controller, tests, web component, schema and migrations `20261107054458_telemedicine_stage2` and `20261107065559_telemedicine_stage3`.
- **Doctor video fee** (`masters.service.ts`, `masters.prisma`, `ward-editor.tsx`), email and reminder changes, portal changes, settings, the patient page, new error codes, ADR 012, backlog, API routes and notification/telemedicine/email docs, and `docs/MedOS-module-coverage.xlsx`.

## Where both sides touched the same area

No file was changed by both sides in conflicting ways, so no line had to be chosen between two versions. The files A changed were taken from A; every other changed file was taken from B.

## Not copied

`node_modules`, build output (`.next`, `dist`, `dist-test`, `.turbo`), `next-env.d.ts` (regenerated by Next.js) and `.local/app-db.env` (this machine's local database settings).

## After copying this folder to a database that already runs

Apply the migrations: `pnpm --filter @medos/database migrate` (adds the two telemedicine migrations and the cashier permission).
